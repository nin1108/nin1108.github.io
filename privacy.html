プライバシーポリシー（knowspace uploader）

最終更新日：2026年11月12日

knowspace uploader（以下「本アプリ」）は、YouTube チャンネル「宇宙を知る（@knowspace1004）」の運営者が、自分のチャンネルに動画を予約投稿するためだけに使用する非公開のツールです。一般の利用者への提供は行っていません。

取得する情報

本アプリは、Google の OAuth 認証を通じて、運営者自身の YouTube アカウントに対する次の権限を取得します。

  • YouTube アカウントの管理（https://www.googleapis.com/auth/youtube）

この権限は、運営者のチャンネルへの動画のアップロード、タイトル・説明文・サムネイルの設定、公開予約の設定、およびそれらの状態の確認にのみ使用します。

情報の保存

  • 認証によって発行されるトークンは、運営者が管理する GitHub リポジトリの暗号化されたシークレット領域にのみ保存します。
  • 本アプリは、運営者以外の利用者の個人情報を取得・保存しません。

第三者への提供

取得した情報を第三者に販売・提供することはありません。

情報の削除・アクセスの取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から、いつでも本アプリのアクセスを取り消せます。

Google API サービスの利用

本アプリによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

YouTube API サービスを利用しています。YouTube の利用規約（https://www.youtube.com/t/terms）および Google のプライバシーポリシー（https://policies.google.com/privacy）が適用されます。

お問い合わせ

YouTube チャンネル「宇宙を知る」（https://www.youtube.com/@knowspace1004）までご連絡ください。
