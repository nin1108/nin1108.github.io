# 企画メモ ep001「もし地球に土星みたいな輪ができたら？」

- ジャンル: 3Dで見る、もしも科学（config/channel.toml の genre.current）
- 状態: 制作完了（state.json 参照）

| 項目 | 内容 |
|---|---|
| 問い | 赤道付近と中緯度では、同じ輪がどう見え方を変える？ |
| 答え（3Dで確認済み） | 北緯35°: 南の空に幅の広い**帯のアーチ**（外縁の最高高度 約33.4°、内縁は地平線すれすれ 約1.3°、両端は方位約110°〜250°で地平線に入る）。赤道: 自分が輪の面の中にいるため輪を**真横から見る**ことになり、天頂を東西に横切る**細い線**になる |
| 答えを映像で証明するカット | ① 同じカメラ設定（南向き・仰角25°・縦画角100°）で2地点を比べる地上カット、② 真上向き全天カメラ（等距離魚眼180°・上=北）の2地点比較、③ 子午面の断面図、④ 輪を見る角度を38°→0°に下げると輪が消えていく宇宙カット |
| 科学的に置いた仮定 | 輪は地球の赤道面にある薄い円環。内縁・外縁は土星の主な輪（C環内縁〜A環外縁）の惑星半径比 1.24〜2.27 をそのまま地球半径 6,378.137 km に当てはめ、内縁 7,909 km・外縁 14,478 km（地表からの高さ 約1,530〜8,100 km）。光学的な濃淡（C環は薄く、B環は濃く、カッシーニの間隙、A環）も同じ比率で配置。季節は6月下旬（太陽赤緯 +23.44°）、両地点とも地方時16時ごろ（時角60°）。観測者の目の高さ1.6 m。地球は球とみなす（扁平率は無視） |
| 誇張・近似（画面と説明欄に明記） | 地上カットの輪の厚みを 8 km に誇張（実際の土星の主な輪は厚さ約10 m級）。断面図の輪の厚み・線の太さも誇張。宇宙カットの地点マーカーは拡大表示。地平線近くで輪が薄れるのは大気による減光の見た目の近似（定量モデルではない） |
| 確認済みの事実 | 土星の主な輪の厚さは典型的に約10 m、輪を真横から見ると消えたように見える（NASA）。C環内縁 74,490 km・A環外縁 136,770 km・土星赤道半径 60,268 km（Miller ら 2023） |
| 概算・推定 | 「現実の地球に輪ができる条件」は扱わない（ロッシュ限界や輪の寿命などは未検討。断定しない） |
| 冒頭1秒の絵 | 上下2分割：上=北緯35°の空にかかる巨大な帯のアーチ、下=赤道の空を縦に切る細い一本線。字幕「同じ輪なのに、見え方がちがう？」 |
| 既存回との違い | 第1回のため比較対象なし。以降の回は「観測位置による見え方の違い」以外の型（断面・スケール比較・立体の動き）も交互に使う |

## 科学監修のメモ
- 解析式（lib/geom.py）: 子午線上の輪の高度 tan(h) = (r cosφ − R) / (r sinφ)。地平線より上に見える経度範囲 r cosθ cosφ > R。
- 3D照合（verify_projection.py → verify_result.json）: 全天カメラで輪あり/なしの差分から測定。
  - 北緯35° 外縁高度 解析 33.43° / 3D 33.66°、内縁 1.27° / 1.26°、高度2°の方位範囲 112.0〜248.0° / 112.0〜247.5°
  - 赤道 線が画像中央の行（天頂）を通り、左右端（東〜西）まで伸びる
- 赤道の観測者は輪の面上にいるため、輪のどの半径の部分も天頂を通る東西の大円上に重なる。厚さ10 mなら天頂方向（1,531 km先）での見かけの太さは約0.0004°。
- 結論の表現: 「赤道では細い線」「真横（遠くから見る角度0°）では輪はほぼ見えない」。実際に観測したかのような表現は使わない。
