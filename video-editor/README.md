# モバイル動画エディター

スマートフォンのブラウザだけで、キーフレームアニメーション・映像エフェクト・テロップ・カラーグレーディング・音声編集を行い、
H.264/AAC の MP4 として書き出せる Web アプリ (PWA) です。外部の有料 API やサーバーは使わず、すべて端末内で処理します。

- 公開 URL: `https://nin1108.github.io/editor/` (このリポジトリの `/editor/` にビルド成果物を配置)
- ソース: `video-editor/`

## 起動方法

```bash
cd video-editor
npm install
npm run dev          # 開発サーバー (http://localhost:5173)
npm run build        # 型チェック + ../editor/ へ本番ビルド
npx vite preview --port 4173   # ビルド結果の確認
npm test             # ユニットテスト (vitest)
node tests/e2e/run.mjs [--long]  # 完成判定 E2E テスト (要: ビルド済み + preview 起動 + ffmpeg)
```

WebCodecs・Service Worker は安全なコンテキスト (https または localhost) でのみ動作します。
スマートフォン実機で開発サーバーを試す場合は、https で公開するか、PC の Chrome のリモートデバッグ経由で localhost を転送してください。

## 公開方法 (GitHub Pages)

1. `cd video-editor && npm run build` で `../editor/` に成果物が出力されます。
2. `editor/` をコミットして `main` に反映すると GitHub Pages で `/editor/` として配信されます。
3. ルートの `.nojekyll` により、`_` で始まるファイルも配信されます (既存の `index.html` / `privacy.html` には影響しません)。

## 技術構成と採用理由

| 技術 | 採用 | 理由 |
| --- | --- | --- |
| React 19 + TypeScript + Vite | ○ | 大規模 UI の保守性。Vite は高速ビルド・コード分割 |
| zustand + immer | ○ | 不変データで Undo/Redo を軽量に実装 (構造共有)。ドラッグ中は 1 操作 = 1 履歴 |
| WebGL2 | ○ (描画の中核) | iOS Safari 15+ / Android Chrome で利用可。Canvas2D の `filter` は Safari で使えないため、エフェクト・ブレンド・3D 変形・カラー補正はすべて GLSL で実装し、ブラウザ間の見た目を揃えた |
| WebGPU | × | iOS Safari の対応が限定的で、WebGL2 で要件を満たせるため不採用 (将来の高速化候補) |
| Canvas 2D | ○ | テキスト (日本語組版・多重縁取り)・図形・パーティクル・グラフの生成。結果を WebGL テクスチャへ |
| WebCodecs + mediabunny | ○ (書き出し・フレーム正確なデコード) | H.264/AAC の MP4 をネイティブ速度で生成。Safari 16.4+ / Chrome 対応 |
| @mediabunny/aac-encoder (WASM) | ○ (フォールバック) | ブラウザが AAC を符号化できない場合 (一部 Safari / Chromium) に使用 |
| MediaRecorder | ○ (フォールバック) | WebCodecs 非対応端末では実時間録画で書き出し |
| FFmpeg.wasm | × | 30MB 超・SharedArrayBuffer (COOP/COEP ヘッダー) が必要で GitHub Pages と相性が悪い。iPhone のメモリ制限上も不利 |
| Web Audio API | ○ | プレビューと書き出し (OfflineAudioContext) で同一のミックスグラフを構築し、結果を一致させる。AudioContext の時計を再生のマスタークロックにして映像を同期 |
| Web Workers | △ | エンコードはブラウザ内部/mediabunny の非同期処理、AAC WASM エンコーダは Worker で動作 |
| IndexedDB | ○ | プロジェクト JSON・素材 Blob・波形・サムネイル・テロッププリセット。自動保存 + 5 分ごとのバックアップ世代 |
| OPFS | ○ (書き出し) | 45 秒を超える書き出しは OPFS へストリーム書き込みしてメモリ使用量を抑える (非対応時はメモリ) |
| PWA | ○ | manifest + 自作 Service Worker (ビルド時にプリキャッシュ一覧を生成)。オフライン起動可 |

### プレビューと書き出しの分離

- **プレビュー**: 画面サイズ × DPR に合わせた低解像度 (上限 1280px、設定で変更可) で描画。動画は `<video>` 要素を実時間再生し、停止中はシークで同期。画像は縮小版を使用。
- **書き出し**: 同じ `Compositor` を出力解像度で使い、動画は WebCodecs でフレーム単位に正確にデコードした**元素材**を使用。画像も原寸。
- 描画コードは共通なので、プレビューと書き出しの見た目は一致します (E2E テストで PSNR を検証)。

### 主なファイル

```
src/model/       データモデル・キーフレーム補間・タイムライン操作・SRT
src/render/      WebGL コンポジター・シェーダー・テキスト/図形/パーティクル生成
src/media/       素材読み込み・動画フレーム供給 (プレビュー/書き出し)・音声ミックス
src/export/      書き出し・端末性能判定
src/presets/     プリセット (171 種類。うち「YMM4テンプレ」39 種類)
src/storage/     IndexedDB
src/ui/          画面 (タイムライン・プレビュー・各パネル)
tests/unit/      ユニットテスト
tests/e2e/       完成判定テスト
```

## 実装済み機能

- 動画/画像/SVG/音声の読み込み (ファイル内容のマジックバイト判定、壊れたファイルの拒否)
- マルチトラックタイムライン (中央固定の再生ヘッド、ピンチで拡大縮小、慣性スクロール、長押しで移動、トラック間移動、トリムハンドル、スナップ、マーカー、波形・サムネイル表示)
- 分割 / 複製 / 削除 / 詰めて削除 / 隙間を詰める / 速度 (0.1〜16 倍) / 逆再生 / 静止画化 / 音声分離 / グループ化 / 親子付け / トラックのロック・非表示・ミュート
- 変形 (X/Y/Z・拡大・回転・3D 回転 X/Y・傾斜・アンカー・不透明度)、クロップ、マスク (矩形/楕円・角丸・ぼかし・反転)、ブレンドモード 13 種、3D レイヤー + 仮想カメラ
- キーフレーム (全数値・色パラメーター、エフェクトのパラメーター含む)、補間 9 種 (リニア/ホールド/イーズイン/アウト/インアウト/カスタムベジェ/バウンス/スプリング/オーバーシュート)、グラフエディター (値グラフ上でキーをドラッグ、速度曲線をベジェハンドルで編集)
- 映像エフェクト 27 種 (グロー/ネオン/モーションブラー/レンズフレア/RGB分離/色収差/グリッチ/ノイズ/残像/カメラシェイク/シャドウ/被写界深度風/ガウシアン・放射状・方向ブラー/光線/フラッシュ/波紋/ウェーブ/魚眼/グラデーション/クロマキー/モザイク/ミラー/反転/ポスタリゼーション/シャープ/走査線)。重ね掛け・並べ替え・キーフレーム制御可
- パーティクル 8 種 (粒子/紙吹雪/火花/雪/星/ボケ/光の粒/雨)、トランジション 19 種
- テロップ: Web フォント 20 種 + 端末フォント + フォントファイル追加、三重縁取り、グラデーション/金属、立体、発光、影、光沢、座布団 (角丸・斜め・枠線)、縦書き、文字間/行間、一文字アニメーション 13 種、マイプリセット保存、SRT 読み込み/書き出し (UTF-8/UTF-16/Shift_JIS 自動判定)
- モーショングラフィックス: 図形 (四角/円/多角形/星/線/矢印/円形ゲージ/SVG パス)、ピクトグラム 34 種、線の描画アニメーション、数値カウンター、タイマー、グラフ (棒/横棒/折れ線/円/ドーナツ)、アニメーション背景 6 種、調整レイヤー
- カラー: 露出/明るさ/コントラスト/ハイライト/シャドウ/白・黒レベル/色温度/色かぶり/彩度/自然な彩度/色相/フェード/ビネット/グレイン/RGB カーブ/3D LUT (.cube)
- 音声: 音量キーフレーム、フェード、3 バンド EQ、コンプレッサー、パン、トラック音量、マスター音量、音割れ防止リミッター、ナレーション録音
- 書き出し: 720p/1080p/1440p/4K、24/30/60fps、ビットレート指定、MP4 (H.264 + AAC)、端末性能判定で非対応解像度を無効化、進捗/残り時間/キャンセル、共有シートから写真に保存
- 自動保存 (0.7 秒デバウンス + ページ離脱時)、URL によるプロジェクト復帰、バックアップから復元、プロジェクト JSON 入出力、縦画面/横画面 (横画面は詳細パネルを右側に常時表示する編集モード)、全画面プレビュー
